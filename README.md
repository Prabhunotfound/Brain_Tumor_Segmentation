# Brain MRI Segmentation

A pipeline for binary segmentation of brain MRI scans using deep learning, comparing UNet, TransUNet, and WaveUNet architectures on the DAC / BRISC dataset.

---

## Setup Instructions

### 1. Cloning the Repo

Clone the repository and navigate into the project directory:

```bash
git clone https://github.com/Prabhunotfound/Brain_Tumor_Segmentation
cd Brain_Tumor_Segmentation
```

### 2. Environment Creation

Create and activate a virtual environment to ensure dependency isolation.

#### Using `venv` (pip)

**Linux/macOS**
```bash
python -m venv venv
source venv/bin/activate
```

**Windows**
```bash
python -m venv venv
venv\Scripts\activate
```

#### Using `conda`
```bash
conda create -n brain-seg python=3.11
conda activate brain-seg
```

### 3. Python Version Verification

This project requires **Python 3.14** for full compatibility with the libraries used. Before proceeding, verify your version:

```bash
python --version
```

If the output is not `Python 3.14.x`, please install the correct version from [python.org](https://www.python.org) before continuing.

### 4. Install Dependencies

Once the correct environment is active, install the required packages. This project relies on several key libraries including `torch`, `albumentations`, `opencv-python-headless`, `medpy`, and `PyWavelets`.

**Using pip:**
```bash
pip install -r requirements.txt
```

## Dataset

This project uses the **DAC / BRISC** brain MRI dataset. Before running any notebook, organise the raw data in the following structure:

```
dataset/
├── raw/
│   ├── train/
│   │   ├── images/          # .jpg MRI slices
│   │   └── masks/           # .png binary masks
│   └── test/
│       ├── images/
│       └── masks/
└── processed/               # Generated by Preprocessing.ipynb
    ├── train/
    ├── val/
    └── test/
```

> **Note:** The notebooks were originally run on **Kaggle** (P100/T4 GPU). Update `CFG.DATA_ROOT` in each model notebook to point to your local dataset path before running.

## Execution Order

Execute the notebooks in the following sequence:

| Step | Notebook | Description |
|------|----------|-------------|
| 1 | `EDA.ipynb` | Explores the raw dataset — file inventory, image shape analysis, intensity distributions, and mask visualisation. |
| 2 | `Preprocessing.ipynb` | Applies CLAHE contrast enhancement, z-score normalisation, and resizes images to 224×224. Splits data into train/val/test and saves as `.npy` files. |
| 3 | `UNet.ipynb` | Trains and evaluates a baseline UNet model. |
| 4 | `TransUNet.ipynb` | Trains and evaluates a hybrid Vision Transformer + CNN segmentation model. |
| 5 | `WaveUNet_v1.ipynb` | Trains and evaluates a UNet variant using Discrete Wavelet Transform for downsampling/upsampling with wavelet-augmented input channels. |
| 6 | `WaveUNet_v2.ipynb` | Extends WaveUNet v1 with a channel attention mechanism for improved feature recalibration. |
